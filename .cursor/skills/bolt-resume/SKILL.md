# 進行中のボルトを再開する

## STEP 1: 現在のボルト状態を確認
以下を順に読む：
1. `docs/aidlc/bolts/` のフォルダ一覧でボルト番号を確認
2. 対象ボルトの `progress.md` を読む（ステータス・作業ログ）
3. `tasks.md` の各チェックを確認する

### 例外処理
- **指定されたボルトが存在しない場合**: 既存ボルトの一覧を提示し、新規作成（bolt-start）を提案する
- **複数のボルトが進行中の場合**: 各ボルトのステータスを一覧で報告し、ユーザーにどのボルトを再開するか選択を求める。1つに絞ってからSTEP 2に進む
- **必要なファイルが不足している場合**（progress.md はあるが tasks.md がない等）: 不足ファイルをユーザーに報告し、テンプレートから作成することを提案する。承認を得てから作成する

## STEP 2: 状況をユーザーに報告
以下の形式で報告する：

```
## ボルト bolt-NNN: <タイトル>

**ステータス**: 🟡 進行中

### 完了済みタスク ✅
- [x] ...

### 未完了タスク 🔲
- [ ] ...

### 次に着手すべきタスク（提案）
<具体的なタスクと理由>
```

## STEP 3: 次タスクの実装方針を提示（会話の反転）
次タスクの実装方針を提示し、ユーザーの承認を得てから実装する。

## STEP 4: タスク完了後の記録更新
タスク完了後は必ず以下を更新する：
- `tasks.md` の該当チェックに `x` を入れる
- `progress.md` の作業ログに完了日時と内容を追記する
- `progress.md` の「参照スキル・ルール」セクションに、今回の作業で参照したスキルファイル（例: `.cursor/skills/bolt-resume/SKILL.md`）やルールファイル（例: `.cursor/rules/bolt-workflow.mdc`）を日付付きで追記する
- 全タスク完了時はステータスを `🟢 完了` に変更する

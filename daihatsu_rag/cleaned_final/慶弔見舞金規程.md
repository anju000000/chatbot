# 株式会社エックス 慶弔見舞金規程

# 第1章 総則

# 第1条（目的）

この規程は、株式会社エックス（以下「会社」という）の従業員に対する慶弔見舞金の支給に関する事項を定めることを目的とする。

# 第2条（適用範囲）

この規程は、就業規則第2条に定める従業員に適用する。ただし、試用期間中の者、その他会社が別途定める者については、この限りではない。

# 第2章 慶弔見舞金の種類及び支給額

# 第3条（結婚祝金）

従業員が結婚したときは、結婚祝金として30,000円を支給する。

# 第4条（出産祝金）

従業員又はその配偶者が出産したときは、出産祝金として子1人につき20,000円を支給する。

# 第5条（死亡弔慰金）

従業員又はその家族が死亡したときは、次の区分により弔慰金を支給する。

(1) 従業員本人が死亡した場合（業務上）：500,000円

(2) 従業員本人が死亡した場合（業務外）：100,000円

(3) 配偶者が死亡した場合：50,000円

- (4) 子が死亡した場合：30,000円

- (5) 父母（配偶者の父母を含む）が死亡した場合：30,000円

- (6) その他会社が認める親族が死亡した場合：10,000円

# 第6条（傷病見舞金）

従業員が業務外の傷病により連続して30日以上欠勤したときは、傷病見舞金として30,000円を支給する。ただし、同一の傷病による支給は1回限りとする。

# 第7条（災害見舞金）

従業員が火災、風水害、その他の災害により、住居又は家財に損害を受けたときは、その損害の程度に応じて、次の区分により災害見舞金を支給する。

(1) 住居が全壊・全焼した場合：100,000円

- (2) 住居が半壊・半焼した場合：50,000円

- (3) 家財に甚大な損害を受けた場合：30,000円

- (4) その他会社が認める場合：【会社が定める額】

# 第3章 申請及び支給

# 第8条（申請手続き）

慶弔見舞金の支給を受けようとする者は、原則として事由発生日から3か月以内に、所定の申請書に事由を証明する書類（住民票、戸籍謄本、死亡診断書、罹災証明書等）を添えて、所属長を経由して人事担当部署に提出しなければならない。

# 第9条（支給時期）

慶弔見舞金は、前条の申請に基づき、原則として申請を受理した日の属する賃金支払日に支給する。

# 第10条（重複支給の制限）

同一の事由に対して、複数の慶弔見舞金が該当する場合は、原則として最も高額なもののみを支給する。

# 第4章 その他

# 第11条（規程の改廃）

この規程の改廃は、取締役会の決議による。

# 附則

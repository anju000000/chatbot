# 株式会社エックス 育児・介護休業等に関する規程

# 第1章 総則

# 第1条（目的）

この規程は、株式会社エックス（以下「会社」という）の就業規則（以下「規則」という）第28条に基づき、労働者の育児休業、介護休業、子の看護休暇、介護休暇、その他育児・介護に関する諸制度について必要な事項を定める。

- 2．この規程に定めのない事項については、育児・介護休業法（以下「法」という）、その他の法令の定めるところによる。

# 第2条（定義）

この規程において、次の各号に掲げる用語の意義は、当該各号に定めるところによる。

- (1) 育児休業：法に定める育児休業をいう。

- (2) 介護休業：法に定める介護休業をいう。

- (3) 子の看護休暇：法に定める子の看護休暇をいう。

- (4) 介護休暇：法に定める介護休暇をいう。

- (5) 対象家族：法に定める配偶者（事実婚を含む）、父母、子、配偶者の父母、祖父母、兄弟姉妹、孫をいう。

- (6) 要介護状態：法に定める負傷、疾病又は身体上若しくは精神上の障害により、2週間以上の期間にわたり常時介護を必要とする状態をいう。

# 第3条（適用範囲）

この規程は、規則第2条に定める会社の労働者に適用する。ただし、第2項から第4項に定める者を除く。

- 2．育児休業、介護休業の適用については、日々雇用される者を除く。

- 3．期間を定めて雇用される労働者については、次の各号のいずれにも該当する場合に限り、育児休業及び介護休業を申し出ることができる。

- (1) 育児休業：申出時点で、子が1歳6か月に達する日までに労働契約（更新される場合は更新後の

契約）の期間が満了することが明らかでないこと。

- (2) 介護休業：申出時点で、介護休業開始予定日から起算して93日を経過する日から6か月を経過する日までに労働契約（更新される場合は更新後の契約）の期間が満了することが明らかでないこと。

- 4．労使協定により、次の各号に該当する労働者からの育児休業、介護休業の申出を拒むことができる。

# (1) 入社1年未満の労働者

- (2) 申出の日から1年以内（介護休業の場合は93日以内）に雇用関係が終了することが明らかな労働者

- (3) 1週間の所定労働日数が2日以下の労働者

第4条（規程の遵守）

会社及び労働者は、この規程を誠実に遵守しなければならない。

第2章育児休業

第5条（育児休業の申出）

- 1歳に満たない子（実子及び養子縁組をした子）を養育する労働者は、会社に申し出ることにより、子が1歳に達する日（誕生日の前日）までの間で希望する期間、育児休業をすることができる。

- 2．配偶者が労働者本人より先に育児休業をしている場合、労働者は子が1歳2か月に達するまでの間で、1歳までの育児休業とは別に、出生日又は出産予定日のいずれか遅い方から1年間を限度として、育児休業（パパ・ママ育休プラス）をすることができる。

- 3．次のいずれかの場合で、労働者が希望するときは、子が1歳6か月に達する日までの間で、育児休業を延長することができる。再度、同様の事情がある場合は、子が2歳に達する日までの間で再延長することができる。

- (1) 保育所等への入所を希望し、申込みを行っているが入所できない場合

(2) 子の養育を行っている配偶者であって、子が1歳に達する日後の期間について常態として子の養育を行う予定であった者が、死亡、負傷、疾病等の事情により、子を養育することが困難になった場合

- 4．育児休業の申出は、原則として、休業開始予定日の1か月前までに、「育児休業申出書」を会社に提出することにより行う。ただし、産後休業に引き続き育児休業を開始する場合のパパ休暇の申

出は、休業開始予定日の2週間前までとする。

- 5．育児休業中の労働者は、休業期間中は業務に従事しないものとする。

第6条（育児休業の申出の撤回等）

労働者は、育児休業開始予定日の前日までは、申出を撤回することができる。

- 2．休業期間中に、子の死亡等により休業の理由が消滅した場合は、その事由が発生した日に育児休業は終了するものとし、当該労働者は速やかに会社に届け出なければならない。

第7条（育児休業期間の変更）

労働者は、育児休業終了予定日の1か月前までに申し出ることにより、当初の終了予定日を1回に限り繰り下げることができる。

# 第8条（育児休業期間中の待遇）

育児休業期間中は、賃金を支給しない。

- 2．育児休業期間は、勤続年数に通算する。ただし、退職金の算定においては、その期間を除外することがある。（※退職金規程による）

- 3．賞与の算定については、育児休業期間は原則として査定対象期間から除外する。

- 4．育児休業期間中の社会保険料（健康保険料、厚生年金保険料）については、法に基づき、労働者負担分及び会社負担分ともに免除される。労働者は会社を通じて手続きを行うものとする。

第9条（子の看護休暇）

小学校就学の始期に達するまでの子を養育する労働者は、会社に申し出ることにより、1年度（4月1日から翌年3月31日まで）において5労働日（対象となる子が2人以上の場合は10労働日）を限度として、子の看護休暇を取得することができる。

- 2．子の看護休暇は、子の負傷、疾病の世話、又は子に予防接種、健康診断を受けさせるために取得することができる。

- 3．子の看護休暇は、1日又は時間単位（※労使協定が必要）で取得することができる。

- 4．子の看護休暇の申出は、原則として事前に「子の看護休暇申出書」を会社に提出することにより行う。ただし、やむを得ない場合は、事後の申出も認める。

- 5．子の看護休暇期間中の賃金は、支給しない。

- 6．労使協定により、次の各号に該当する労働者からの子の看護休暇の申出を拒むことができる。

- (1) 入社6か月未満の労働者

- (2) 1週間の所定労働日数が2日以下の労働者

- (3) 時間単位での取得が困難な業務に従事する労働者（時間単位取得の場合）

第4章介護休業

第10条（介護休業の申出）

要介護状態にある対象家族を介護する労働者は、会社に申し出ることにより、対象家族1人につき、通算して93日の範囲内で、3回まで分割して介護休業をすることができる。

- 2．介護休業の申出は、原則として、休業開始予定日の2週間前までに、「介護休業申出書」に対象家族が要介護状態にあることを証明する書類（診断書等）を添えて会社に提出することにより行う。

- 3．介護休業中の労働者は、休業期間中は業務に従事しないものとする。

第11条（介護休業の申出の撤回等）

労働者は、介護休業開始予定日の前日までは、申出を撤回することができる。

- 2．休業期間中に、対象家族の死亡等により休業の理由が消滅した場合は、その事由が発生した日に介護休業は終了するものとし、当該労働者は速やかに会社に届け出なければならない。

第12条（介護休業期間中の待遇）

介護休業期間中は、賃金を支給しない。

- 2．介護休業期間は、勤続年数に通算する。ただし、退職金の算定においては、その期間を除外することがある。（※退職金規程による）

- 3．賞与の算定については、介護休業期間は原則として査定対象期間から除外する。

- 4．介護休業期間中の社会保険料の免除措置はない。

第5章介護休暇

第13条（介護休暇）

要介護状態にある対象家族を介護する労働者は、会社に申し出ることにより、1年度（4月1日から翌年3月31日まで）において5労働日（対象家族が2人以上の場合は10労働日）を限度として、介護休暇を取得することができる。

- 2．介護休暇は、対象家族の介護、その他世話（通院の付添い、介護サービスの手続き代行等）のために取得することができる。

- 3．介護休暇は、1日又は時間単位（※労使協定が必要）で取得することができる。

- 4．介護休暇の申出は、原則として事前に「介護休暇申出書」を会社に提出することにより行う。ただし、やむを得ない場合は、事後の申出も認める。

- 5．介護休暇期間中の賃金は、支給しない。

- 6．労使協定により、次の各号に該当する労働者からの介護休暇の申出を拒むことができる。

- (1) 入社6か月未満の労働者

- (2) 1週間の所定労働日数が2日以下の労働者

- (3) 時間単位での取得が困難な業務に従事する労働者（時間単位取得の場合）

- 第6章育児・介護のための所定外労働、時間外労働及び深夜業の制限

第14条（所定外労働の制限）

- 3歳に満たない子を養育する労働者、又は要介護状態にある対象家族を介護する労働者が申し出た場合、事業の正常な運営を妨げる場合を除き、所定労働時間を超えて労働させることはない。

- 2．申出は、1回につき1か月以上1年以内の期間について、開始予定日の1か月前までに「所定外労働制限申出書」を提出することにより行う。

# 第15条（時間外労働の制限）

小学校就学の始期に達するまでの子を養育する労働者、又は要介護状態にある対象家族を介護する労働者が申し出た場合、事業の正常な運営を妨げる場合を除き、1か月について24時間、1年について150時間を超える時間外労働をさせることはない。

- 2．申出は、1回につき1か月以上1年以内の期間について、開始予定日の1か月前までに「時間外労働制限申出書」を提出することにより行う。

# 第16条（深夜業の制限）

小学校就学の始期に達するまでの子を養育する労働者、又は要介護状態にある対象家族を介護する労働者が申し出た場合、事業の正常な運営を妨げる場合を除き、午後10時から午前5時までの間（深夜）に労働させることはない。ただし、次の各号のいずれかに該当する労働者を除く。

# (1) 日々雇用される者

# (2) 入社1年未満の者

- (3) 深夜においてその子又は対象家族を常態として保育又は介護できる同居の家族がいる者

- (4) 1週間の所定労働日数が2日以下の者

# (5) 所定労働時間の全部が深夜にある者

- 2．申出は、1回につき1か月以上6か月以内の期間について、開始予定日の1か月前までに「深夜業制限申出書」を提出することにより行う。

第17条（育児のための所定労働時間の短縮措置）

- 3歳に満たない子を養育する労働者であって、育児休業をしていないものは、会社に申し出ることにより、1日の所定労働時間を原則として6時間とする短時間勤務制度を利用することができる。

- 2．適用期間は、子が3歳に達する日までとする。

- 3．利用を希望する労働者は、原則として開始予定日の1か月前までに「育児短時間勤務申出書」を会社に提出する。

- 4．短時間勤務中の労働者の賃金、その他労働条件については、短縮された労働時間に応じて変更する。詳細は個別の労働条件通知書で明示する。

- 5．会社は、業務の都合その他やむを得ない事由がある場合、短時間勤務制度に代えて、フレックスタイム制度、始業・終業時刻の繰上げ・繰下げ（時差出勤）、事業所内保育施設の設置運営その他これに準ずる便宜を供与することがある。

# 第18条（介護のための所定労働時間の短縮措置等）

要介護状態にある対象家族を介護する労働者は、会社に申し出ることにより、利用開始から3年の間で2回まで、以下のいずれかの措置を利用することができる。

- (1) 所定労働時間の短縮措置（1日の所定労働時間を原則として6時間とする等）

# (2) フレックスタイム制度

- (3) 始業・終業時刻の繰上げ・繰下げ（時差出勤）

- (4) 労働者が利用する介護サービスの費用の助成その他これに準ずる制度

- 2．利用を希望する労働者は、原則として開始予定日の2週間前までに「介護のための短時間勤務等申出書」を会社に提出する。

- 3．措置中の労働者の賃金、その他労働条件については、利用する措置に応じて変更する。詳細は個別の労働条件通知書で明示する。

第8章不利益取扱いの禁止及びハラスメントの防止

# 第19条（不利益取扱いの禁止）

会社は、労働者がこの規程に定める育児休業、介護休業、子の看護休暇、介護休暇、その他各制度の申出又は取得等を理由として、解雇その他不利益な取扱いを行わない。

第20条（育児・介護休業等に関するハラスメントの防止）

会社及び労働者は、規則第14条に基づき、職場において、育児休業・介護休業その他の子の養育又は家族の介護に関する制度の利用に関する言動により、他の労働者の就業環境を害するようなことをしてはならない。

- 2．会社は、育児・介護休業等に関するハラスメントの防止のため、規則第12条各号に掲げる措置を講じる。

# 第9章 復職

# 第21条（復職）

育児休業又は介護休業の期間が満了したとき、又は休業期間中に休業事由が消滅したことにより休業が終了したときは、労働者は原則として休業開始前の職務に復帰するものとする。

- 2．会社は、前項の場合において、組織の変更等やむを得ない事情があるときは、労働者の能力及び経験等を考慮の上、他の職務に配置転換を命じることがある。

第10章育児休業給付及び介護休業給付

第22条（給付金の受給手続き）

育児休業又は介護休業を取得し、雇用保険の受給資格を満たす労働者は、育児休業給付金又は介護休業給付金の支給を受けることができる。

- 2．会社は、労働者が給付金の支給を受けるために必要な手続きについて協力する。手続きは原則として労働者本人が行うものとする。

# 第11章 その他

第23条（法令との関係）

この規程に定めのない事項及び法改正によりこの規程の内容と異なる取扱いが必要となった場合は、法の定めるところによる。

# 第24条（規程の改廃）

この規程の改廃は、就業規則の変更手続きに準じて行う。

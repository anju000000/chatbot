# 株式会社エックス 安全衛生管理規程

# 第1章 総則

# （目的）

第1条 この規程は、労働安全衛生法（以下「法」という。）及び関係法令に基づき、株式会社エックス（以下「会社」という。）における安全衛生管理体制、安全衛生教育、労働災害防止その他従業員の安全衛生に関する基本的事項を定め、快適な職場環境の実現と従業員の安全及び健康の確保を図ることを目的とする。

# （適用範囲）

第2条 この規程は、会社に所属するすべての従業員（正社員、パートタイム労働者、アルバイト等を含む。）に適用する。

# 第2章 安全衛生管理体制

# （総括安全衛生管理者）

第3条 会社は、法に基づき、本社に総括安全衛生管理者を選任し、次の業務を統括させる。

1. 従業員の健康障害を防止するための対策の樹立に関すること。

2. 従業員の安全のための対策の樹立に関すること。

3. 労働災害の原因の調査及び再発防止対策に関すること。

4. 前各号に掲げるもののほか、従業員の安全及び健康の保持に関し重要なこと。

（安全管理者）

第4条 会社は、法に基づき、事業場ごとに安全管理者を選任し、次の業務を行わせる。

1. 建設物、設備、作業場所又は作業方法に危険がある場合における応急措置又は適当な対策に関すること。

2. 安全装置、保護具その他設備の点検及び整備に関すること。

3. 作業の方法又は作業手順を決定し、労働者を指揮すること。

4. 前各号に掲げるもののほか、労働者の危険を防止するために必要な措置に関すること。

（衛生管理者）

第5条 会社は、法に基づき、事業場ごとに衛生管理者を選任し、次の業務を行わせる。

1. 従業員の健康に異常がないかどうかの確認及び健康の保持増進のための措置に関すること。

2. 作業環境の衛生上の調査及び改善に関すること。

3. 労働災害の原因の調査及び再発防止対策のうち、衛生に係るものに関すること。

4. 前各号に掲げるもののほか、従業員の健康を保持するために必要な措置に関すること。

（安全衛生委員会）

第6条 会社は、法に基づき、本社に安全衛生委員会を設置する。

2. 安全衛生委員会は、次の事項を調査審議し、会社に意見を述べる。

1. 従業員の健康障害を防止するための対策に関すること。

2. 従業員の安全のための対策に関すること。

3. 労働災害の原因及び再発防止対策に関すること。

4. 前各号に掲げるもののほか、従業員の安全及び健康の保持に関する重要な事項に関すること。

5. 安全衛生委員会の構成、運営その他必要な事項は、別に定める。

# 第3章 安全衛生教育

（安全衛生教育）

第7条 会社は、従業員に対し、雇入れ時、配置換え時、作業内容変更時その他必要な時期に、法に基づく安全衛生教育を実施する。

2. 前項の教育の内容、時間その他必要な事項は、法令及び会社の定めるところによる。

# 第4章 労働災害防止

（労働災害防止）

第8条 会社は、労働災害の防止のため、次の措置を講じる。

1. 危険又は有害な作業を行う場所には、必要な安全装置又は保護具を設けること。

2. 作業の方法、手順その他必要な事項について、作業手順書等を作成し、従業員に周知徹底すること。

3. 定期的に作業場所を巡視し、危険又は有害な状況がないかどうかを確認すること。

4. その他、労働災害の防止に必要な措置を講じること。

# （労働者の責務）

第9条 従業員は、労働災害を防止するため、次の事項を遵守しなければならない。

1. 会社が定める安全衛生に関する規定、指示等を遵守すること。

2. 作業手順書等を熟読し、その内容に従って作業を行うこと。

3. 常に作業場所の安全に注意し、危険を発見した場合は、直ちに上司又は安全衛生管理者に報告すること。

4. 会社が支給する保護具を適切に着用し、作業中はこれを外さないこと。

5. 健康に留意し、常に万全の状態で作業を行うこと。

6. 飲酒、薬物その他の理由により、正常な作業ができないおそれがある状態で作業を行わないこと。

# 第5章 健康管理

（健康診断）

第10条 会社は、従業員に対し、法に基づく健康診断を実施する。

2. 従業員は、正当な理由なく前項の健康診断を拒むことはできない。

3. 健康診断の結果、異常が発見された場合は、会社の指示に従い、必要な措置を講じなければならない。

（受診命令）

第11条 会社は、従業員の健康状態に異常があると認める場合、又は従業員が精神若しくは心身上の問題により業務に支障をきたすおそれがあると認める場合は、当該従業員に対し、医師の診断を受けることを命じることができる。

2. 従業員は、正当な理由なく前項の命令を拒むことはできない。

# 第6章 補則

（安全衛生に関する規定の作成）

第12条 会社は、この規程の実施に必要な事項について、別途規定を定めることができる。

（規程の改廃）

第13条 この規程の改廃は、安全衛生委員会の意見を聴いて行う。

# 附則

この規則は、2017年4月1日から改定施行する。この規則は、2020年4月1日から改定施行する。この規則は、2025年2月1日から改定施行する。

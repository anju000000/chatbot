# 株式会社エックス 通勤手当支給規程

# 第1章 総則

# （目的）

# 第1条

この規程は、株式会社エックス（以下「会社」という。）の就業規則第2条に基づき、従業員の通勤手当の支給に関する事項を定めるものである。

# （適用範囲）

# 第2条

この規程は、就業規則第2条に定める全ての従業員に適用する。ただし、通勤の実態がない従業員、または通勤距離が片道2km 未満の従業員を除く。

# （通勤手当の定義）

# 第3条

通勤手当とは、従業員が通勤のために必要とする交通費の実費を補填するために、会社が支給する手当をいう。

# 第2章 支給要件及び支給額

# （支給要件）

# 第4条

通勤手当は、次の各号のいずれかに該当する従業員に支給する。

- (1) 公共交通機関（電車、バス等）を利用して通勤する者

- (2) 自転車、自家用車その他の交通用具（以下「自家用車等」という。）を利用して通勤する者で、通勤距離が片道2km 以上の者

# （通勤経路及び方法の届出）

# 第5条

通勤手当の支給を受けようとする従業員は、就業規則第5条に基づき、最も経済的かつ合理的な通勤経路及び方法を記載した「通勤経路届」を会社に提出しなければならない。

2. 会社は、提出された通勤経路及び方法が、経済性・合理性の観点から著しく不適当であると認める場合は、変更を求めることがある。

3. 通勤経路又は方法に変更があった場合は、速やかに「通勤経路変更届」を提出しなければならない。

# （公共交通機関利用者の支給額）

# 第6条

公共交通機関を利用する従業員に対しては、前条に基づき届け出られた通勤経路及び方法による1か月分の通勤定期券の購入金額、または最も経済的な運賃の実費相当額を支給する。

2. 通勤定期券の購入が可能な区間については、原則として通勤定期券を購入するものとする。

3. 新幹線、特急列車、有料の高速バス等の特別料金を必要とする交通機関の利用は、会社が業務上の必要性または通勤事情を勘案し、特に承認した場合を除き、原則として認めない。

# （自家用車等利用者の支給額）

# 第7条

自家用車等を利用する従業員に対しては、通勤距離に応じて、以下の区分に基づき算定した額を支給する。

- (1) 片道の通勤距離が2km 以上10km 未満：月額4,200円

- (2) 片道の通勤距離が10km 以上15km 未満：月額7,100円

- (3) 片道の通勤距離が15km 以上25km 未満：月額12,900円

- (4) 片道の通勤距離が25km 以上35km 未満：月額18,700円

- (5) 片道の通勤距離が35km 以上45km 未満：月額24,400円

- (6) 片道の通勤距離が45km 以上55km 未満：月額28,000円

- (7) 片道の通勤距離が55km 以上：月額31,600円

2. 通勤距離は、自宅から就業場所までの最も合理的な経路による距離とする。

3. 自家用車等を利用する場合、会社は駐車場を提供しない。駐車場の確保及び費用は従業員の自己負担とする。

4. 自家用車等での通勤を希望する者は、別途定める「車両通勤許可申請書」を提出し、会社の許可を得なければならない。許可にあたっては、任意保険（対人・対物無制限）への加入を必須条件とする。

# （支給上限）

# 第8条

通勤手当の支給額は、月額50,000円を上限とする。

# （通勤手当の不支給）

# 第9条

次の各号の一に該当する場合には、通勤手当を支給しない。

- (1) 欠勤、休職、その他事由により、月の全所定労働日に出勤しなかった場合。ただし、年次有給休暇、特別休暇等、会社が認めた休暇による場合を除く。

- (2) 届け出た通勤経路及び方法によらないで通勤した場合

- (3) 不正な手段により通勤手当を受給しようとした場合、または受給した場合

# 第3章 支給方法その他

（支給日）

# 第10条

通勤手当は、毎月の給与支給日に、その月の分を支給する。ただし、通勤定期券代については、その有効期間に応じて、1か月、3か月、または6か月分をまとめて支給することができる。

# （支給額の変更）

# 第11条

通勤手当の支給額は、運賃改定、通勤経路・方法の変更、転居等により通勤事情に変更があった場合、変更事由が発生した日の属する月の翌月から改定する。

2. 従業員は、通勤事情に変更があった場合は、速やかに第5条第3項に定める届出を行わなければならない。届出を怠ったことにより過払いが生じた場合、会社は当該過払い分を返還請求することができる。

# （出勤日数に応じた調整）

# 第12条

月の中途で採用された者、または退職する者については、その月の実出勤日数に応じて日割り計算により支給する。ただし、通勤定期券代を支給する場合は、購入した定期券の有効期間及び実利用状況を考慮して調整する。

# （非課税限度額）

# 第13条

通勤手当の支給は、所得税法に定める非課税限度額の範囲内で行うものとする。非課税限度額を超える部分については、給与所得として課税対象となる。

# （規程の改廃）

# 第14条

この規程の改廃は、取締役会の決議による。

# 附則

この規則は、2017年4月1日から改定施行する。この規則は、2020年4月1日から改定施行する。この規則は、2025年2月1日から改定施行する。

# ダイハツ規約クレンジングルール

あなたはこのフォルダのMarkdownファイルを規約文書として整形する専門家です。

【必須ルール】
- 余分な半角・全角スペースをすべて1つに統一（連続スペースは削除）
- 行頭・行末の不要なスペースを完全に削除
- 不自然な改行を可能な限り繋げる（1つの条項はできるだけ1〜数行にまとめる）
- 見出しは「# タイトル」の形式に統一（# の後に必ず半角スペース）
- 条項番号は「第15条」のように統一（全角・半角・スペースのゆれを吸収）
- 句読点の前後に不要なスペースを入れない
- 連続空行は最大2行までに制限
- 全体として「読みやすい法律・規約文章」にする

処理の流れ：
1. inputフォルダ（または指定フォルダ）内の全.mdファイルを読み込む
2. 各ファイルを上記ルールでクレンジング
3. outputフォルダに同じファイル名で保存
4. 変更前後の差分を簡単に報告
